# Karnataka potato data-collection protocol

## Capture unit

The primary unit is a **commercial batch**. Within each batch, 20–50 randomly sampled tubers should be photographed from multiple sides. The system must retain batch ID, tuber ID and capture session so frames cannot leak across data splits.

## Minimum capture set per batch

- overhead batch photograph;
- at least two sides per sampled tuber;
- one image with a calibrated size/colour reference card;
- measured weight and maximum/minimum diameter for a subset;
- close-up of each visible defect;
- optional cut image for internal defects, clearly marked as destructive inspection.

## Expert annotation

Two graders independently record:

- defect type and mask/bounding polygon;
- affected surface percentage;
- severity (minor, moderate, severe);
- freshness/firmness observation;
- commercial grade under the selected profile;
- fresh-market/processor/reject acceptance;
- disagreement and final consensus.

## Sampling design

Collect across:

- Kufri Jyoti and other target varieties;
- at least four Karnataka potato-producing/marketing regions;
- multiple farms, traders, storage facilities and mandis;
- low-cost and high-end smartphones;
- indoor, shade and diffuse daylight;
- harvest, transit and multiple storage ages;
- both common and rare defects.

## Privacy and consent

- obtain farmer/trader consent;
- avoid faces, documents, phone numbers and exact home addresses;
- assign pseudonymous farm IDs;
- document whether images may be redistributed or only used internally;
- allow removal requests before dataset release.
